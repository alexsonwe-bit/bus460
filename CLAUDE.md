# «Автобус 460» · Котельники ⇄ Коломна

Веб-приложение с расписанием автобуса 460, ставится на iPhone как PWA (Safari → «Поделиться» → «На экран „Домой“»). Пользуются владелец и его девушка. Сайт публичный, без авторизации.

Сайт: https://alexsonwe-bit.github.io/bus460/ — работает, проверен с iPhone.

## Как работать с владельцем

- Общаться по-русски. Инструкции — коротко, пошагово, без лишней техники.
- **Договорённость: владелец пишет «Обнови» → проверить расписание на tutu.ru и подготовить изменения** (обновить `BUILTIN` в `index.html`, поднять версию кэша, отправить на проверку).
- Не обещать, что сайт «никогда не сломается», что VPN «никогда не понадобится» или что автономный HTML равноценен PWA — прежние категоричные ответы были ошибкой.

## Возможности

- Переключение направления Котельники → Коломна и обратно.
- Ближайший рейс, обратный отсчёт, прибытие и остановка в Коломне.
- Все рейсы выбранного дня: прошедшие приглушены, следующий выделен. После окончания рейсов — первый завтрашний.
- Выбор даты: стрелки, календарь, «Сегодня».
- Ручная правка расписания и импорт из скопированного текста tutu.ru.
- Светлая и тёмная темы; офлайн-кэш через service worker.

## Файлы

Статика без сборщика, backend и БД.

- `index.html` — интерфейс, расписание (`var BUILTIN`), логика, парсер.
- `sw.js` — офлайн-кэш. Текущая версия — `bus460-v4`.
- `manifest.webmanifest` — `start_url` и `scope` = `./`, чтобы работало в подпапке `/bus460/`. Пути относительные — не ломать.
- `icon-180.png`, `icon-192.png`, `icon-512.png` — номер 460 на тёмном фоне.

## Деплой

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Файлы лежат прямо в корне (не в папке `bus460-site`). Владелец обычно загружает вручную: Add file → Upload files → те же имена → Commit changes.

- При изменении кэшируемых файлов повышать `CACHE` в `sw.js` (`bus460-v4` → `bus460-v5`).
- После деплоя проверить, что Pages отдаёт новые файлы, и что установленная PWA получила новую версию.

## Данные расписания

Источник:
- https://bus.tutu.ru/raspisanie/gorod_Kotelniki/gorod_Kolomna/
- https://bus.tutu.ru/raspisanie/gorod_Kolomna/gorod_Kotelniki/

Последняя сверка — 12.10.2026: все 20 рейсов совпали с tutu.ru (на tutu.ru дата изменения 28.01.2026, по 10 ежедневных рейсов в каждую сторону). После этого не проверялось.

Встроенное расписание (`BUILTIN`):
- Из Котельников: 06:55, 08:15, 10:15, 11:15, 12:35, 14:05, 15:35, 17:00, 19:05, 21:35. Рейсы 19:05 и 21:35 — до ул. Спирина (Колычёво), остальные — до автовокзала Коломна.
- Из Коломны: 04:00, 04:30, 06:30, 08:30, 09:45, 11:00, 12:30, 13:30, 16:00, 19:10. 04:00 и 04:30 — с ул. Спирина, остальные — с автовокзала.
- В пути обычно 1 ч 40 мин; с ул. Спирина — 2 ч.

Автоматического получения с tutu.ru нет (браузер не может читать tutu.ru из-за междоменных ограничений, сервера-посредника нет). Импорт в приложении: скопировать страницу tutu.ru → вставить → «Разобрать» → проверить → «Сохранить». Сохранённое живёт только в браузере этого устройства, между телефонами не синхронизируется.

Парсер:
- Извлекает отправление, прибытие, остановку; исключает маршрут 333; сортирует.
- Поддерживает оба формата tutu.ru: новый (`№ 460м. Котельники – …` в одной строке) и старый (отдельная строка `460`, строка платформ `8,9`). При изменении проверять на обоих: по 10 рейсов с правильными остановками.
- Зависит от структуры скопированного текста — может снова потребовать ремонта.
- Пользовательский текст выводить через текстовые узлы, не через HTML.

## Дизайн

- Компактно для телефона, русские подписи. Нейтральные поверхности, синий акцент; крупное тёмное табло с янтарным временем; моноширинные цифры.
- Склонения: «1 рейс», «2 рейса», «5 рейсов».
- **Обязательное посвящение внизу: «Специально для моей любимой кошки ♥».** Сердечко розовое, мягко пульсирует; при `prefers-reduced-motion` анимация выключена. Не трогать.

## Решения и отвергнутое

- PWA вместо нативного приложения — без App Store, Mac и Xcode.
- Встроенное расписание + офлайн-кэш — работает при плохой связи.
- GitHub Pages — бесплатный HTTPS, не зависит от входа в claude.ai. Сайт публичный; ограничение доступа не реализовано.
- Отвергнуто: Claude Artifact (проблемы доступа на iPhone), Google Drive и Яндекс.Диск (не подходят для PWA), Yandex Cloud Object Storage, Cloudflare Pages + Access, Netlify, Vercel, российские хостинги.
- Автономный HTML-файл — запасной вариант, работа JS в «Файлах» iOS не подтверждена; локальная копия может быть устаревшей.
